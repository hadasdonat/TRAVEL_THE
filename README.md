# פרויקט: טיולים בעולם – אתר סטטי רספונסיבי

הפרויקט עומד בדרישות **פרק א – יחידות 13–20**: אינטרנט סטטי עשיר, רספונסיבי, עם קישורים, תמונות, טבלאות, רשימות, טפסים וניווט; שימוש ב‑Grid/Flexbox, Iframe/Embed/Media, ו‑Media Queries לפחות לשני/שלושה גדלים. הפרדת קבצי HTML ו‑CSS נשמרה.

## מבנה
- `index.html` – דף בית + Hero + וידאו YouTube (iframe) + מפה (iframe) + וידאו HTML5 + PDF (embed) + רשימות + Grid/Flex.
- `destinations.html` – עוגנים פנימיים (#beaches/#treks/#cities), רשימות, טבלת השוואה, details/summary.
- `gallery.html` – גריד תמונות (CSS Grid).
- `tools.html` – כרטיסי כלים (Flex/Grid), קישורים חיצוניים (לפחות 3).
- `about.html` – הסבר על האתר.
- `contact.html` – טופס מלא (input/email/select/radio/checkbox/textarea + ולידציה בסיסית).
- `styles.css` – עיצוב רספונסיבי, Grid + Flexbox, אנימציות.

## כיצד להריץ
פתחו את `index.html` בדפדפן. אין תלות בשרת.

## התאמות מהירות
- החלפת נושא: ערכו טקסטים/תמונות/קישורים.
- הוספת נקודות שבירה: הוסיפו media queries ב־`styles.css`.
- הוספת עוד עמודים: העתיקו שלד בסיסי של עמוד.

> טיפים: שמרו ב‑Git, עבדו בזוג, חלקו משימות לאפיון/תכנון/מימוש/בדיקות/הצגה.
